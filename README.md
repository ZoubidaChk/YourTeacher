YourTeacher : is a simple English-learning app that works completely offline. Practice English from beginner to advanced level, at your own pace.

What you can do : 
- Learn reading, vocabulary, and grammar.
- Practice listening, speaking, and writing.
- Test yourself with quizzes and vocabulary games.
- Track your progress, XP, and learning streak.
- Use light or dark mode.
- Create multiple learner profiles.

The lessons cover five levels: A1, A2, B1, B2, and C1.
Run the app
Download the installer from the Releases page, or use the portable version without a traditional installation.
To run from source, install Node.js 18.17 or later, then run:
 npm install
 npm start

Build the Windows app : 
npm run build
